# Twisted Creations — Website

Your one-page website. Everything is in `index.html` + the `assets/` folder.

## What's on the site
- **Books** — all three books with cover art and Amazon buy links
- **Game** — Star Catcher Deluxe with a Play Free button
- **Music** — YouTube channel link + streaming services note
- **Creations** — Sam-Sam ghost keychain (tagged GIVEAWAY), haunted house wall art (tagged DISPLAY), plus a "coming soon" card
- **Giveaway Club** — free monthly giveaway email signup (needs your email wired in — see below)
- **QR code** — `twisted-creations-qr.png` points at the planned site address, ready to print on your 3D prints

## Get it live (free, about 10 minutes)
1. On GitHub, create a new public repository named `twisted-creations`.
2. Upload everything from this folder (index.html, assets/, qr png) into it.
3. Go to Settings → Pages → set Source to "Deploy from a branch", Branch: main, folder: /(root). Save.
4. Your site will be live at **https://thebeast02.github.io/twisted-creations/** within a couple of minutes.

## One thing to send Muse when you're ready
- **The live site link** — once it's up, send the address. If it differs from the planned one above, you'll get a fresh QR code in under a minute.

## Editing later
Open `index.html` in any text editor. Each section is clearly labeled (BOOKS, GAME, MUSIC, CREATIONS, GIVEAWAY CLUB). To add a new print, copy one of the creation cards and swap the image, title, and tag.
